# 한자 공부 앱 작업 체크리스트

어린이와 가족이 교과서 단원과 특정 급수시험의 한자를 공부하는 웹앱을 만든다. 뜻과 음을 익히는 문제, 한자를 고르는 문제, 필순과 모양을 익히는 쓰기 기능을 제공한다. 쓰기는 한 획을 쓰고 손을 떼면 원본 입력을 판정하고, 통과한 획을 정자 획으로 즉시 교체한다.

작성일: 2026-10-13 / 최근 수정일: 2026-11-21

현재 단계: 교과서 단원순 데이터와 637자의 뜻·음·두음법칙 추가 허용 음(`allowedSounds` 29자)·`draft` 획 데이터 연결까지 완료했고, 2026-11-21 트랙 A에서 [02 명세서](02-학습-채점-획보정-명세서.md)의 출제·채점·복습·회차·정답률·쓰기 기본 규칙과 1차 범위·저장·대상 기기 결정을 모두 확정했다. 이번 스프린트에서 `01~06` 설계·기획 문서를 완비한 뒤, 다음 실제 실행 단계로 `03` 획 보정 시제품 실사용 허용 오차 검증(`strokeStatus`의 `draft → verified` 승격), 소장 실물 교과서 대조, `07~10` 본 앱 구현·테스트를 진행한다.

개인 시간이 날 때 작업 순서에 따라 하나씩 진행한다. 마감일이나 예상 소요 기간을 정하지 않고, 체크리스트로 완료 여부를 관리한다.

## 진행 규칙

- 한 번에 한 단계를 진행하고, 완료 조건을 충족한 항목만 `[x]`로 바꾼다.
- 초안 작성과 검증 완료를 구분한다. 문서가 있다고 기능이 완료된 것으로 표시하지 않는다.
- 작업을 마칠 때 현재 단계, 체크 상태, 다음 할 일을 갱신한다.
- 미정 사항은 결정 목록에 남기고, 해당 결정이 필요한 단계 전에 확정한다.
- 획 보정 시제품 검증을 통과하기 전에는 본 앱의 쓰기 기능을 확정하지 않는다.
- 이 체크리스트는 진행 관리용이다. 자동 알림이나 정기 실행은 설정하지 않는다.
