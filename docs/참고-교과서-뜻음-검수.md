# 교과서 한자 뜻과 음 검수

천재교과서 2022 개정 중학교 한문 안대회 교과서의 공식 공개 미리보기에서 새 한자란의 뜻과 음을 확인했다. 20개 단원 638개 항목을 한자 기본 정보 637자에 연결했으며, 복수 독음을 구분한 뜻·음 묶음은 642개다.

검수일: 2026-10-19 / 데이터 버전: 0.2.0

## 검수 기준과 결과

- 새 한자란 62개 페이지의 공개 원문 텍스트와 638개 항목의 한자·순서를 전수 대조했다. 637자 모두 뜻·음이 있으며 누락 및 중복 글자 간 충돌이 없다.
- 교과서 표기의 쉼표는 같은 음에 연결된 복수 뜻으로, 음·뜻 묶음 사이의 슬래시는 별도 독음으로 구분했다. `不 불/부 아니다`는 동일한 뜻에 두 음이 연결된다.
- 복수 독음 5자와 텍스트 추출에서 누락된 `厖`을 화면으로 대조했다. 시각 대조 페이지는 74, 84, 110, 122, 130, 150쪽이다. 전체 페이지를 한 장씩 육안 대조했다는 의미는 아니다.
- 6단원과 10단원의 `者`는 모두 `자 사람`으로 일치한다. 하나의 기본 정보에 두 출처를 연결했다.
- 데이터 검사에서 20개 단원·638개 항목·637자·642개 뜻·음 묶음·638개 출처 연결을 확인했다. 검수 자료와 다른 뜻 연결 및 중복 글자의 출처 누락을 의도적으로 넣은 메모리상 검사에서도 오류가 검출되었다. 실제 저장 데이터는 변경하지 않았다.
- 공개 텍스트에서 빠진 `厖`의 글리프는 150쪽 화면을 기준으로 복원했으며, 뜻·음은 `방 크다`다.
- `readingStatus: verified`는 이 공식 공개 미리보기의 새 한자란과 대조했다는 의미다. 소장 책의 최종 판본, 학교 시험 범위, 주관식 허용 답안, 필순 검증을 뜻하지 않는다.
