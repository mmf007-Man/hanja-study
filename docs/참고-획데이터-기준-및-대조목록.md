# 획 데이터 기준 및 대조 목록

천재교과서 2022 개정 중학교 한문 안대회 교과서 637자 학습 앱의 쓰기 기능 및 획 보정(Stroke Assist) 시제품 개발을 위한 획 데이터 요구 규격과 대조 기준을 정의한다. 한국 교과서 한자 자형·필순과 오픈소스 획 데이터(중국·일본) 간 차이가 발생하기 쉬운 집중 검수 대상 한자 159자를 선별하고 검수 기준을 확립한다.

작성일: 2026-11-17 / 데이터 버전: 0.2.0 / 대상 한자: 637자 (집중 검수 159자)

## 1. 획 데이터 스키마 및 연동 요구사항

앱의 학습과 채점 무결성을 보장하기 위해 한자 데이터(`data/characters.json`)의 `strokeData`와 `strokeStatus`는 다음 규칙을 준수한다.

### 1.1 strokeData 필드 스키마

```json
{
  "id": "hanja-6F22",
  "character": "漢",
  "codePoint": "U+6F22",
  "readings": [{ "sound": "한", "meanings": ["한나라"] }],
  "readingStatus": "verified",
  "strokeData": {
    "provider": "makemeahanzi",
    "key": "6F22",
    "version": "2024.1.0"
  },
  "strokeStatus": "pending"
}
```

- `provider` (문자열): 획 데이터 제공처 식별자 (예: `makemeahanzi`, `kanjivg`, `hanzi-writer-data`, 자체 제작 `internal` 등).
- `key` (문자열): 제공처 저장소 내 해당 한자의 고유 식별자 (일반적으로 유니코드 16진수 코드포인트 대문자 또는 글자 자체).
- `version` (문자열): 제공처 데이터의 릴리스 버전 또는 커밋 식별자.
- `strokeStatus` (문자열): 4단계 상태 머신을 따른다.
  - `pending` (대기): 초기 등록 상태. 외부 데이터 연결 및 한국 자형 검증이 아직 진행되지 않음.
  - `draft` (초안): 제공처 데이터 후보가 연결되었으나, 한국 교과서 필순·자형 대조 검수를 통과하지 않은 상태.
  - `verified` (검증완료): 한국 교과서 기준 자형, 총 획수, 획 순서 대조를 통과하고 시제품에서 정상 렌더링·판정이 확인된 상태 (`scripts/validate_data.py`의 엄격 검사 통과 필수).
  - `unavailable` (미지원/제외): 제공처에 데이터가 없거나, 자형 차이로 인해 현재 지원할 수 없어 쓰기 출제에서 제외할 상태.

### 1.2 문제 출제 연동 규칙

- **뜻·음 퀴즈(객관식/주관식)**: `readingStatus == 'verified'`인 한자만 출제한다.
- **쓰기 문제(획 보정 포함)**: `strokeStatus == 'verified'`이며 실제 유효한 벡터 획 데이터를 로드할 수 있는 한자만 출제 후보로 사용한다.
- **미지원 한자 자동 제외**: `strokeStatus`가 `pending`, `draft`, `unavailable`인 한자는 쓰기 문제 출제 목록에서 자동으로 제외되며, 앱 오류를 유발하지 않는다.

## 2. 획 보정(어시스트) 흐름 및 시제품 최소 데이터 규격

`docs/02-학습-채점-획보정-명세서.md` 및 `docs/00-작업-일정표.md`의 합의 사항에 따라 획 보정 시제품과 앱 쓰기 기능은 다음 흐름으로 작동한다.

### 2.1 획 보정 기본 동작 원칙

1. **한 획 완료 시점 판정**: 사용자가 마우스 드래그나 화면 터치/펜으로 한 획을 긋고 손(포인터)을 떼면(`pointerup` / `touchend`), 원본 입력 궤적을 판정 엔진에 전달한다.
2. **통과 시 정자 획 즉시 스냅(교체)**: 필순, 시작 위치, 획 진행 방향, 길이가 정해진 오차 범위 내에 들어오면, 거친 손글씨 입력을 화면에서 즉시 깨끗한 '정자 벡터 획'으로 교체하여 안착시키고 다음 획 입력 대기 상태로 전환한다.
3. **실패 시 자동 정답 교체 금지**: 획 판정을 통과하지 못한 잘못된 입력은 절대로 정답 획으로 자동 변환해주지 않는다. 잘못된 입력 획만 지우고, 이전에 성공한 획들은 그대로 유지한 채 현재 획을 다시 쓰도록 유도한다.
4. **정체성 훼손 방지 (미세 오차 허용 경계)**: `土`(흙 토: 위 가로가 짧고 아래 가로가 긺)와 `士`(선비 사: 위 가로가 길고 아래 가로가 짧음), `日`(날 일)과 `曰`(가로 왈)처럼 획의 상대적 길이나 위치 차이가 글자의 정체성을 결정하는 경우, 판정 알고리즘이 이를 뭉개고 무조건 보정하지 않도록 엄격한 판정 임계값을 적용한다.

### 2.2 획 보정 시제품 연동에 필요한 최소 4대 데이터 요소

| 데이터 요소 | 설명 | 필수 속성 / 형식 예시 |
|---|---|---|
| **1. 정규 획 순서 (Stroke Order)** | 한자의 총 획수 및 1번째부터 N번째까지의 정규 필순 인덱스 | `strokeIndex: 0..N-1`, `totalStrokes: N` |
| **2. 획별 정자 벡터 경로 (SVG Outline)** | 화면에 즉시 교체 렌더링할 정자 획의 외곽선 벡터 패스 (굵기·모양 완비) | `<path d="M... Z" fill="#000"/>` (SVG Path Data) |
| **3. 판정용 중심선 궤적 (Medians)** | 사용자의 원본 획 좌표와 대조할 획 중심선 좌표 시퀀스 (시작점, 굴곡점, 끝점, 방향) | `[[x1, y1], [x2, y2], ...]`, 시작점 허용 반경, 방향 벡터 |
| **4. 기준 좌표계 (Bounding Box / ViewBox)** | 캔버스 화면 크기에 무관하게 일관된 판정을 수행하기 위한 정규화 좌표계 | `viewBox="0 0 1024 1024"` 등 고정 종횡비 좌표계 |

## 5. 자형·필순 차이 유형별 분류 및 주의사항

집중 검수 대상 159자는 다음 11개 주요 차이 유형으로 분류된다.

1. **교과서 특이 보존 정자 (8자)**: `姉`, `敎`, `鷄`, `兎`, `豐`, `厖`, `內`, `全` 등 교과서가 보존한 고유 정체자로, 중국 간체자나 일본 신자체, 대만 변체와 명백히 다른 글리프를 유지해야 함. 특히 `厖`(150쪽)은 외부 데이터셋 미지원 누락 위험 1순위임.
2. **자형 미세차이 계열 (22자)**: `說`, `悅`, `堂`, `賞`, `常`, `嘗`, `靑`, `情`, `靜`, `直`, `植`, `德`, `者`, `都`, `骨`, `體`, `角`, `解`, `令`, `命`, `今`, `念` 등 내부 획의 결합선, 점(丶) 유무, 상단 생(生) vs 龶, 돌출 여부 등 폰트별 미세 차이가 있는 한자.
3. **艹 (초두머리) 계열 (14자)**: `草`, `花`, `落`, `苦`, `藥`, `萬`, `葉`, `若`, `莫`, `華`, `藝`, `螢`, `暮`, `茂`. 한국 전통 자형은 4획(十十)으로 교수되나, 중국/일본 오픈소스는 대부분 3획(一ㅣㅣ)으로 제작되어 총 획수와 필순 불일치가 필연적으로 발생함.
4. **辶 (책받침) 계열 (15자)**: `近`, `選`, `進`, `退`, `過`, `速`, `造`, `遠`, `追`, `連`, `道`, `逸`, `達`, `遺`, `遇`. 한국 전통 강희자전체는 점 둘(4획)이나 오픈소스는 점 하나(3획)인 경우가 많으며, '몸통 선작성 후 책받침 후작성' 필순 엄수 필요.
5. **阝 (좌부변/우부방) 계열 (7자)**: `防`, `降`, `除`, `陽`, `限`, `邑`, `郞`, `都`. 3획(㇇→弯→ㅣ) 획순과 함께, 좌부변은 먼저 쓰고 우부방은 나중에 쓰는 공간적 선후 관계 판정 필요.
6. **示 / 礻 (보일 시) 계열 (5자)**: `祖`, `祝`, `福`, `視`, `禮`. 示(5획)와 변형 礻(4획: 점→꺾임→세로→점)의 글리프 차이 및 필순 검증.
7. **食 / 飠 (밥 식) 계열 (4자)**: `食`, `飮`, `養`, `餘`. 한국 전통 번체 飠(8획) 정자 유지 여부 및 중국 饣(3획) 축약 방지.
8. **門 (문 문) 계열 (7자)**: `門`, `聞`, `問`, `開`, `閉`, `間`, `關`. 한국 정자 8획 좌세로→가로꺾임 필순 유지 및 중국 门(3획) 간체화 방지.

1. **오픈소스 데이터 자동 매핑 (1단계)**: MakeMeAHanzi 번체/KanjiVG 데이터셋에서 637자의 유니코드 키를 자동 매핑하고, 결측 글자(예: `厖` 등)와 총 획수 불일치 글자를 1차 스크리닝한다.

3. **자체 보정 데이터 구축 (`internal`) (3단계)**: 자형이 틀리거나 필순이 다른 한자는 Inkscape/SVG 도구로 획 패스와 메디안 좌표를 교정하여 `provider: internal`로 등록한다.
