# 학습과 채점 및 획 보정 명세서

교과서 한자 학습 앱의 출제, 정답 처리, 기록, 획 보정 규칙을 결정한다. 사용자와 합의한 항목부터 기록하며 미정 항목을 순서대로 확정한다.

작성일: 2026-10-19 / 최근 수정일: 2026-11-21

상태: 1차 명세 확정(시제품 실사용 검증 항목 제외). 2026-11-21까지 합의한 출제·채점·허용 답안·복습·20문제 혼합 학습·진행 중 정오/점수 표시·회차/중도 이탈·정답률·쓰기 기본 규칙을 모두 반영했다. 1차 버전은 천재교과서(안대회) 20단원 637자 완성을 우선하며, 기기 내 브라우저 저장(`LocalStorage` + JSON 백업)과 가족 프로필 전환·하루 도전까지 지원한다. 쓰기 획 판정의 허용 오차와 지원 자형·필순 세부 기준은 03 시제품 실사용 검증 후 확정하며, 전체 진행 상태는 [작업 체크리스트](00-작업-일정표.md)에서 관리한다.

## 확정한 규칙

### 한자를 보고 뜻과 음 맞히기

- 한 문제에서 한자를 보여주고 뜻과 음을 함께 묻는다.
- 뜻과 음을 서로 다른 문제로 나누어 출제하지 않는다.
- 뜻의 정답 여부와 음의 정답 여부를 각각 기록한다.
- 한쪽만 맞힌 경우에도 어떤 항목을 맞히고 틀렸는지 구분할 수 있어야 한다.

예를 들어 `漢`을 보여주면 교과서 기준 뜻 `한나라`와 음 `한`을 함께 묻는다. 기록은 다음 네 가지를 구분한다.

| 뜻 판정 | 음 판정 | 기록에서 구분할 상태 |
|---|---|---|
| 정답 | 정답 | 뜻과 음 모두 맞힘 |
| 정답 | 오답 | 뜻만 맞힘 |
| 오답 | 정답 | 음만 맞힘 |
| 오답 | 오답 | 뜻과 음 모두 틀림 |

복수 독음 한자는 뜻과 음이 같은 뜻·음 묶음에 속하는지도 확인한다. 오답 복습 포함 조건과 ‘모르겠어요’ 처리는 아래의 규칙을 적용한다. 뜻·음의 빈 답안은 일반 제출을 허용하지 않으며, 문항 전체 정답률·개별 정답률 계산과 중도 이탈 처리는 아래의 해당 규칙을 따른다.

### 뜻과 음 문제의 점수

한자를 보고 뜻·음을 맞히는 문제는 두 항목이 모두 맞고 올바른 한 쌍을 이루어야 점수를 얻는다. 부분 점수는 주지 않는다.

| 뜻 판정 | 음 판정 | 문항 점수 |
|---|---|---:|
| 정답 | 정답 | 같은 뜻·음 쌍이면 2점 |
| 정답 | 오답 | 0점 |
| 오답 | 정답 | 0점 |
| 오답 | 오답 | 0점 |

0점인 경우에도 뜻과 음의 정답 여부는 각각 보존한다. 점수가 같다는 이유로 ‘뜻만 맞힘’, ‘음만 맞힘’, ‘둘 다 틀림’을 같은 기록으로 합치지 않는다. 뜻·음 → 한자 객관식과 한자 쓰기 문제도 정답 2점·오답 0점으로 전 유형 배점을 통일한다. (1차 버전은 한 기기 내 하루 도전까지 구현하며, 주간 순위 경쟁 및 서버 동기화는 2차 확장으로 분리한다.)

뜻과 음이 각각 해당 한자에 존재하더라도 서로 다른 쌍에서 가져온 조합은 0점이다. 개별 판정 외에 쌍의 일치 여부도 구분할 수 있도록 기록한다.

### ‘모르겠어요’ 버튼

- 답을 모를 때 선택할 수 있는 ‘모르겠어요’ 버튼을 제공한다. 답을 선택하거나 입력하지 않아도 사용할 수 있다.
- 버튼을 누르면 해당 문항을 0점으로 처리하고 정답을 보여준 뒤 오답 복습 대상으로 등록한다.
- 결과에는 ‘모르겠어요’를 선택했다는 사유를 별도로 기록한다. 직접 답을 제출해 틀린 경우, 빈 답안 제출, 화면만 보고 중도 이탈한 경우와 구분한다.
- 뜻·음 문제에서도 문항의 ‘모르겠어요’ 결과와 뜻·음 개별 판정을 구분한다. 버튼을 눌렀다는 이유만으로 뜻과 음을 각각 입력했다가 틀린 것으로 기록하지 않는다.
- 복습 중 이 버튼을 누르면 해당 항목은 미완료로 남고 연속 정답 횟수는 0으로 초기화한다. 완료했던 항목이라면 기존 규칙대로 복습 대상으로 되돌리며 과거 기록은 보존한다.
- 버튼 선택 자체가 해당 문항의 결과를 확정한다. 일반 제출 버튼을 추가로 누를 필요는 없다.

뜻·음 중 한쪽을 모르면 부분 답안을 제출하는 대신 문항 전체의 ‘모르겠어요’ 버튼을 사용한다. 이 경우 입력하거나 선택해 둔 한쪽 답만 별도로 채점하지 않는다. ‘모르겠어요’는 문항 전체 정답률의 분모에는 포함하고 뜻·음 개별 정답률의 분모에서는 제외하며(별도 카운트 표시), 중도 이탈은 모든 정답률 분모에서 제외한다.

### 뜻·음 문제의 제출 가능 조건

- 한자 → 뜻·음 문제는 뜻과 음을 모두 답해야 일반 제출을 허용한다. 한쪽만 답하거나 두 항목 모두 비어 있는 상태에서는 제출 버튼을 비활성화한다.
- 객관식은 뜻 보기와 음 보기에서 각각 하나씩 선택해야 한다.
- 주관식은 뜻과 음 입력 칸에 각각 공백을 제외한 내용이 있어야 한다. 공백만 입력한 칸은 빈 칸으로 취급한다.
- 두 항목을 채웠는지만 제출 전에 확인하며, 정답 여부는 제출한 뒤 판정한다. 입력 내용이 정답인지에 따라 제출 버튼을 활성화하지 않는다.
- 한쪽을 모르면 답을 완성하거나 문항 전체의 ‘모르겠어요’ 버튼을 사용한다. ‘모르겠어요’는 두 항목의 입력·선택 여부와 관계없이 사용할 수 있다.

### 일반 학습의 한 회차 문제 수

- 일반 학습은 한 회차 기본 20문제로 구성한다.
- 한자를 보고 뜻과 음을 함께 묻는 문제는 두 항목을 답하더라도 1문제로 센다. 뜻 문제와 음 문제를 각각 1문제로 세지 않는다.
- 이 문제 수는 일반 학습의 기본값이다. 오답 복습의 연속 2회 정답 완료 기준이나 사이에 다른 문제 1개를 넣는 규칙을 변경하지 않는다.
- 일반 학습 회차를 마치면 기존 공개 규칙에 따라 결과 화면에서 정답을 한꺼번에 보여준다. ‘모르겠어요’ 문항의 즉시 공개 예외는 유지한다.

- 선택한 단원의 출제 가능한 한자가 20자보다 적으면, 먼저 단원 전체 한자를 1회씩 출제한 뒤 부족한 문항은 개인 누적 출제 횟수가 적은 한자부터 채워 20문제를 맞춘다. 이때 같은 한자가 바로 연달아 나오지 않도록 연속 중복 배치를 금지한다(출제 가능 한자가 1자인 단원만 예외).
- 선택한 단원의 출제 가능한 한자가 20자 이상이면, 한 회차 안에서 같은 한자를 중복 출제하지 않는다.
- 부족분을 채우기 위해 정답 한자를 다른 단원에서 가져오지 않는다. 오답 보기만 필요에 따라 같은 교과서의 다른 단원에서 보충하는 기존 규칙을 유지한다.
- 반복 출제된 문제도 각각 별도의 문항으로 센다. 같은 한자를 다시 출제하는 것과 동일한 진행 중 문항을 새로고침하는 것은 구분한다.
- 반복되는 한자의 뜻·음 정답 쌍은 일반 출제의 개인 누적 출제 횟수·마지막 출제 시각 우선 규칙을 따른다. 오답 복습에서는 틀렸던 정답 쌍을 유지한다.
- 선택한 범위나 유형에 출제 가능한 한자가 없거나 데이터가 부족하면, 시작 전 선택 화면에서 불가 사유를 안내하고 시작 버튼을 비활성화한다.

유형별 문항 수는 아래의 균등 배분 규칙을 적용한다.

### 일반 학습의 문제 유형 선택

- 학습 시작 전에 원하는 문제 유형을 하나 또는 여러 개 선택할 수 있다.
- 하나만 선택하면 해당 유형으로 풀고, 여러 개 선택하면 선택한 유형을 한 회차 안에서 섞어 푼다. 선택하지 않은 유형은 출제하지 않는다.
- 한 회차는 선택한 유형을 합쳐 총 20문제로 구성한다. 유형마다 20문제를 별도로 생성하지 않는다.
- 각 문항은 해당 유형의 기존 입력·제출·채점 규칙을 적용한다. 혼합 학습에서 틀린 항목도 기존처럼 틀렸던 형식으로 복습한다.

- 선택한 유형별 문항 수는 가능한 균등하게 자동 배분한다. 총합은 20문제이며 유형 간 문항 수 차이는 최대 1문제로 한다.
- 1개 유형은 20문제, 2개 유형은 각 10문제, 3개 유형은 7·7·6문제, 4개 유형은 각 5문제로 구성한다.
- 선택한 유형 수로 20을 나눈 몫을 각 유형에 배정하고, 나머지 문항은 해당 개수의 유형에 1문제씩 추가한다. 사용자에게 유형별 문제 수를 직접 지정하도록 요구하지 않는다.
- 3개 유형을 선택해 7·7·6문제로 배분할 때는 매 회차 무작위로 1개 유형에 6문제를 배정한다(나머지 2개 유형은 각 7문제).

- 일반 학습에서 여러 유형을 선택하면 유형별 문항 수를 먼저 배분한 뒤 출제 순서를 무작위로 섞는다. 유형별로 묶어서 출제하지 않는다.
- 순서를 섞어도 총 20문제와 유형별로 배정된 문항 수는 유지한다. 매 문항의 유형을 독립적으로 무작위 선택하여 배분 수가 달라지게 하지 않는다.
- 같은 유형이 연속해서 나올 수 있다. 오답 복습에는 기존의 원래 형식 유지·다른 문제 1개를 사이에 두는 규칙을 적용한다.

선택한 범위에서 특정 유형의 출제 가능 데이터가 부족하거나 출제가 불가능할 때는 시작 전 선택 화면에서 불가 사유를 안내하고 시작 버튼을 비활성화한다. 단, 혼합 유형 중 일부 유형만 출제가 불가능하거나 부족하면 출제 가능한 유효 유형으로 문항 수를 재분배할 수 있음을 함께 안내한다. 쓰기 유형의 제공 범위는 획 판정·보정 시제품 검증과 데이터 검수(`verified`) 상태에 따라 확정한다.

### 진행 중 정오·점수 표시와 정답 공개 시점

- 일반 제출로 답한 문항의 **정오 여부(정답/오답)와 획득 점수(2점/0점)는 제출 직후 즉시 표시**한다.
- 틀렸을 때의 **정답 내용(올바른 뜻·음 또는 정답 한자)**은 매 문제 직후 공개하지 않고, 학습 회차가 끝난 뒤 결과 화면에서 한꺼번에 보여준다.
- 제출 시 답안을 확정하고 채점·기록하는 기존 규칙은 유지한다. 채점 시점 및 정오·점수 표시 시점과 오답의 정답 내용 공개 시점을 구분한다.
- ‘모르겠어요’를 선택한 문항만 예외로 즉시 정답을 공개하고, 기존의 0점 처리·오답 복습 등록 규칙을 적용한다.
- 일반 제출 오답 문항의 정답을 제출 직후 보기 강조나 정답 문구 등으로 미리 보여주지 않는다.

쓰기 문제의 매 획 판정·보정과 점선 가이드 표시는 아래의 쓰기 규칙을 따른다.

### 학습 회차의 시작·종료·이어하기와 중도 이탈 처리

- 사용자가 ‘시작’ 버튼을 누르면 새 학습 회차가 생성된다.
- 일반 학습 회차는 20문제를 모두 완료하거나 사용자가 ‘학습 끝내기’(중도 종료)를 선택할 때 종료한다.
- 학습 도중 브라우저를 새로고침하거나 나갔다가 재접속하면 새 회차를 생성하지 않고 진행 중이던 동일 회차를 이어서 진행하며, 해당 회차에 누적된 복습 연속 정답 횟수도 그대로 보존한다.
- ‘학습 끝내기’로 중도 종료하면 결과 화면에는 이미 일반 제출 또는 ‘모르겠어요’로 응답을 확정한 문항까지만 정답 내용과 점수를 공개한다.
- 화면에 이미 표시되었으나 답안을 제출하지 않고 중도 종료한 문항은 **‘중도 이탈’**로 별도 기록하며, 0점 처리하되 오답 복습 대상에는 등록하지 않는다.
- 아직 학습 화면에 표시되지 않은 남은 문항은 출제 및 결과 기록에서 제외한다.

### 정답률 계산 기준

- **문항 전체 정답률**: `문항 정답(2점) 수 ÷ 확정 응답 문항 수(일반 제출 + ‘모르겠어요’)`로 계산한다. ‘중도 이탈’과 미표시 문항은 분모에서 제외한다.
- **뜻·음 개별 정답률**: 한자 → 뜻·음 문제에서 `일반 제출 문항`만 분모로 삼아 뜻 정답률과 음 정답률을 각각 계산한다. ‘모르겠어요’와 ‘중도 이탈’ 문항은 개별 정답률 분모에서 제외하며, ‘모르겠어요’ 선택 횟수는 결과 화면에 별도 카운트로 표시한다.

### 힌트와 제출 후 재시도

- 1차 버전의 객관식·주관식 문항에서는 힌트를 제공하지 않는다(한자 쓰기 문항의 획 점선 가이드와 동음·동의 특정용 부수·총획 힌트만 별도 쓰기 규칙으로 설계한다).
- 일반 학습과 오답 복습 모두 한 번 문항을 제출한 뒤에는 같은 자리에서 즉시 재시도를 허용하지 않는다. 틀린 문항은 오답 복습 재출제 규칙을 통해 다시 도전한다.

### 뜻·음 문제의 오답 복습 포함 기준

- 한자를 보고 뜻·음을 답하는 객관식과 주관식에서 뜻이나 음 중 하나라도 틀리면 오답 복습에 포함한다. 둘 다 틀린 경우도 포함한다.
- 뜻과 음이 각각 해당 한자에 존재하더라도 서로 다른 뜻·음 쌍을 섞어 답했다면 오답 복습에 포함한다.
- 뜻 오류, 음 오류, 뜻·음 쌍 불일치를 구분해 기록하고 복습 대상에 포함된 이유를 표시한다. 같은 문항에 오류가 여러 개 있어도 복습 항목을 오류 개수만큼 중복 생성하지 않는다.
- 올바른 뜻·음 한 쌍으로 정답을 제출한 문항은 이 기준의 오답 복습 대상에 추가하지 않는다. 복수 독음 주관식에서 모든 쌍을 답해야 한다는 조건은 추가하지 않는다.

예를 들어 `樂`에 `즐겁다·악`이라고 답하면 뜻·음 쌍 불일치로 0점을 기록하고 오답 복습에 포함한다.

복습 문제 형식은 아래의 원래 형식 유지 규칙을 적용한다. ‘모르겠어요’는 복습에 포함하며, 뜻·음의 빈 답안은 일반 제출할 수 없다. ‘뜻·음 → 한자 객관식’에서 일반 오답을 제출하거나 ‘모르겠어요’를 선택한 경우에도 원래 형식 그대로 오답 복습에 포함한다. 반면 화면 표시 후 미제출한 ‘중도 이탈’ 문항은 오답 복습에 등록하지 않는다. (1차 객관식·주관식은 힌트를 제공하지 않는다.)

### 한자 → 뜻·음 오답 복습의 문제 형식

- 객관식에서 틀린 항목은 객관식으로, 주관식에서 틀린 항목은 주관식으로 복습한다.
- 객관식 복습도 뜻 보기 4개와 음 보기 4개에서 각각 하나를 골라 함께 제출한다.
- 주관식 복습도 뜻 입력 칸과 음 입력 칸을 따로 두고 함께 제출한다. 기존 허용 답안과 올바른 한 쌍 인정 규칙을 적용한다.
- 한쪽만 틀렸더라도 기존 문항 형식대로 뜻과 음을 함께 묻고, 두 항목의 정답 여부와 쌍의 일치 여부를 구분한다.
- 같은 한자를 객관식과 주관식에서 모두 틀렸다면 각 형식의 복습 상태와 연속 정답 횟수를 구분한다. 다른 형식의 정답으로 해당 항목의 복습을 완료 처리하지 않는다.

### 한자 → 뜻·음 객관식 복습의 보기 구성

- 틀렸던 문항의 뜻·음 정답 쌍을 유지한다. 예를 들어 `樂`의 `즐겁다·락`을 묻던 문제에서 틀렸다면 복습에서도 이 쌍을 정답으로 둔다.
- 새로운 복습 문항을 낼 때마다 뜻 영역과 음 영역의 오답 보기 3개를 각각 다시 선정하고, 정답을 포함한 각 영역의 보기 순서도 새로 섞는다.
- 오답 후보는 선택한 단원에서 우선 고르고, 부족하면 같은 교과서의 다른 단원에서 보충한다. 다른 올바른 답과 중복 보기를 제외하며, 각 영역에 정답이 정확히 하나인지 확인한다.
- 새로 구성한다는 것은 후보를 다시 선정한다는 뜻이며, 이전 오답 보기와 일부가 겹칠 수 있다. 후보가 부족하다고 유효하지 않은 오답을 넣지 않는다.
- 복습할 정답 쌍은 일반 출제의 덜 출제한 쌍 우선 규칙으로 교체하지 않는다. 다른 쌍을 맞힌 결과로 이 객관식 복습 항목을 완료 처리하지 않는다.
- 동일한 진행 중 문항의 화면 재렌더링·새로고침은 새 출제가 아니므로 이미 구성한 보기와 순서를 유지한다.

주관식 복습은 기존처럼 허용된 올바른 한 쌍이면 정답으로 인정한다. 이번 결정은 객관식 복습의 정답 쌍과 보기 구성에 적용한다.

### 오답 복습 항목의 재출제 간격

- 같은 복습 항목은 바로 연달아 출제하지 않고, 다른 문제 1개를 사이에 둔 뒤 다시 출제한다. 기본 흐름은 `A → 다른 문제 1개 → A`다.
- 맞혔지만 아직 연속 2회에 도달하지 않은 항목과 다시 틀린 항목 모두 이 규칙을 적용한다. 완료된 항목을 연속 정답 횟수를 채우기 위해 계속 반복하지 않는다.
- 다른 문제를 푸는 동안 해당 항목의 연속 정답 횟수는 유지한다. 다른 항목을 틀렸다는 이유로 이 항목의 연속 정답 횟수를 초기화하지 않는다.
- 같은 회차에서 A 정답 → B 문제 → A 정답이면 A는 연속 2회 정답으로 복습 완료한다. A 정답 → B 문제 → A 오답이면 A의 연속 정답 횟수를 0으로 초기화한다.
- 한자 → 뜻·음 객관식 복습의 재출제 시에도 틀렸던 정답 쌍은 유지하고 오답 보기와 순서는 새로 구성한다.

- 미완료 복습 항목이 여러 개일 때는 **먼저 틀린 순(FIFO)**을 우선 적용하고, 같은 우선순위에서는 **연속 정답 횟수가 적은 순**으로 출제한다. 단, 직전에 출제한 동일 항목은 연속으로 배치하지 않는다.
- 미완료 복습 항목이 하나만 남으면 사용자가 선택한 단원의 다른 한자(개인 누적 출제 횟수가 적은 한자 우선)로 일반 학습 문제 1개를 구성하여 사이에 넣고, 남은 복습 항목을 다시 출제한다. 선택한 단원 안에 출제 가능한 다른 한자가 없으면 같은 교과서의 다른 단원 한자에서 일반 문제 1개를 삽입한다.
- 사이에 넣는 문제의 정답 한자는 남은 복습 항목의 한자와 달라야 한다. 다른 독음이나 다른 문제 형식으로 같은 한자를 다시 묻는 것으로 대체하지 않는다.
- 다른 한자 문제를 풀고 돌아오는 과정은 같은 학습 회차 안에서 진행한다. 남은 복습 항목의 연속 정답 횟수는 유지하며, 사이에 넣은 문제의 결과를 그 항목의 정답 횟수에 합산하지 않는다.
- 사이에 넣는 일반 문제도 기존 채점·오답 복습 포함 규칙을 따른다. 사이에 넣은 일반 문제에서 새 오답이 발생하면 즉시 대기 중인 복습 목록에 편입한다.

새 회차를 시작하면 미완료 항목의 연속 정답 횟수를 초기화하는 규칙은 유지한다. ‘뜻·음 → 한자 객관식’의 오답 복습 역시 원래 형식 그대로(정답 한자 유지, 오답 보기 3개와 보기 순서 재구성) 출제한다.

### 오답 복습 완료와 기록 보존

- 오답 복습은 한 학습 회차 안에서 해당 복습 항목을 연속 2번 맞히면 완료로 처리한다.
- 연속 정답 횟수는 복습 항목별로 관리한다. 첫 정답이면 1회, 이어서 해당 항목을 다시 맞히면 2회가 되어 완료한다. 다른 항목의 결과와 섞어 계산하지 않는다.
- 해당 항목을 중간에 틀리면 연속 정답 횟수를 0으로 초기화한다. 정답 → 오답 → 정답은 연속 1회 상태이므로 아직 완료가 아니다.
- 뜻·음 문제에서는 기존 문항 정답 기준을 적용한다. 뜻과 음이 맞는 한 쌍이어야 연속 정답으로 센다. 한쪽만 맞거나 서로 다른 쌍을 섞은 답은 오답이다. 복수 독음 주관식의 모든 쌍을 답할 필요는 없다.
- 복습을 완료해도 과거 오답 기록은 삭제하거나 정답으로 덮어쓰지 않는다. 최초 오답 내용·판정과 이후 복습 결과, 복습 완료 상태를 구분하여 보존한다.

- 완료한 복습 항목을 나중에 다시 틀리면 자동으로 복습 대상으로 되돌린다. 현재 상태를 복습 필요로 바꾸고 연속 정답 횟수는 0부터 다시 시작한다.
- 다시 복습 대상으로 돌아온 항목도 연속 2번 정답이면 완료하는 기존 기준을 적용한다.
- 이전 완료 이력은 삭제하거나 취소된 기록으로 덮어쓰지 않는다. 이전 완료 이력, 새 오답 기록과 현재 복습 상태를 구분하여 보존한다.

- 새 학습 회차를 시작하면 미완료 복습 항목의 연속 정답 횟수는 0으로 초기화한다. 이전 회차에서 1번 맞힌 결과를 새 회차의 연속 정답 횟수에 합산하지 않는다.
- 회차 변경으로 이미 완료된 복습 항목을 복습 필요로 되돌리지는 않는다. 완료 후 다시 틀렸을 때에만 앞서 정한 복습 복귀 규칙을 적용한다.
- 회차별 연속 정답 횟수를 초기화해도 과거 답안·오답·완료 이력은 보존한다. 뜻·음 쌍을 골고루 출제하기 위한 개인 누적 출제 횟수와 마지막 출제 시각도 유지한다.

- 복습 회차는 대기 중인 모든 복습 항목이 연속 2회 정답으로 완료될 때 종료한다. (사이에 넣은 일반 문제에서 발생한 새 오답은 즉시 복습 목록에 편입되어 회차 종료 조건에 포함되며, 사용자가 원할 때는 언제든 중도 종료할 수 있다.)
- 일반 학습 회차에서 우연히 맞힌 결과는 미완료 복습 항목의 복습 연속 정답 횟수에 합산하지 않는다. 복습 완료 판정은 오답 복습 회차 안에서 연속 2회 맞힌 결과만 인정한다.

학습 회차의 시작·종료·이어하기 경계와 객관식·주관식 힌트 미제공·즉시 재시도 불허 규칙은 앞선 해당 절을 따른다. (1차 개인 누적 출제·복습 기록은 기기 내 `LocalStorage`에 가족 프로필별로 분리 저장하며, JSON 내보내기/가져오기로 백업한다.)

### 객관식 보기 개수

- 객관식은 4지선다로 출제한다.
- 보기는 정답 1개와 오답 3개로 구성한다.

### 객관식 뜻과 음 선택 및 제출

- 한자를 보고 뜻·음을 맞히는 객관식은 같은 문제 안에 뜻 선택 영역과 음 선택 영역을 둔다.
- 뜻 보기 4개 중 하나, 음 보기 4개 중 하나를 각각 고른다. 각 영역은 정답 1개와 오답 3개로 구성한다.
- 선택한 뜻과 음을 함께 제출한다. 제출 시 두 항목을 각각 판정하고 정답 여부를 따로 기록한다.
- 뜻을 선택한 것만으로 먼저 채점하거나 정답을 공개하지 않는다. 음도 동일하게 함께 제출할 때 판정한다.

뜻과 음을 각각 하나씩 선택해야 일반 제출을 허용한다. 한쪽을 모르면 앞서 정한 문항 전체의 ‘모르겠어요’ 처리를 적용한다.

### 복수 독음 한자의 객관식

- 단어나 문장 없이 한자만 보여주고 뜻과 음을 묻는다.
- 출제 대상인 뜻·음 묶음 하나를 선택하여, 그 묶음의 뜻 하나와 음 하나를 각각의 정답 보기로 넣는다.
- 뜻 보기 4개와 음 보기 4개를 따로 제시하고 함께 제출하는 기존 방식은 유지한다. 뜻·음을 합친 한 쌍을 하나의 선택지로 제시하는 방식으로 바꾸지 않는다.
- 각 영역의 나머지 3개는 오답 보기로 구성한다. 해당 한자의 다른 올바른 뜻이나 음, 검수·등록된 동의 표현과 허용 발음을 오답 보기에 넣지 않는다.
- 같은 뜻·음 묶음에 뜻 표현이 여러 개 있더라도 뜻 영역에는 정답 표현 하나만 넣는다. 영역 안에서 같은 답에 해당하는 보기를 중복 제시하지 않는다.

예를 들어 `樂`의 정답을 `즐겁다·락`으로 구성했다면 뜻 보기에는 `즐겁다`, 음 보기에는 `락`을 넣고, 다른 올바른 답인 `노래`와 `악`은 오답 보기에서 제외한다. 반대로 `노래·악`을 정답으로 구성할 수도 있다.

출제 시 각 영역의 정답이 정확히 하나이고 두 정답이 같은 뜻·음 묶음인지 검사해야 한다. 오답 후보는 아래의 단원 우선·같은 교과서 보충 규칙을 적용한다. 일반 출제에서는 뜻·음 묶음을 아래의 덜 출제한 쌍 우선 규칙으로 선택하고, 오답 복습에서는 틀렸던 문항의 정답 쌍을 유지한다.

### 한자 → 뜻·음 객관식의 복수 뜻·음 출제 빈도

- 출제할 한자에 뜻·음 쌍이 여러 개이면, 출제 가능한 쌍 중 출제 횟수가 적은 쌍을 우선 선택한다.
- 예를 들어 `樂`의 `즐겁다·락`이 더 많이 출제되었다면 `노래·악`을 우선하여 한쪽에 치우치지 않도록 한다.
- 뜻과 음을 각각 따로 고르지 않고, 같은 뜻·음 묶음을 하나의 단위로 선택한다. 다른 올바른 뜻·음을 오답 보기에서 제외하는 기존 규칙도 유지한다.
- 이 규칙은 한자 → 뜻·음 객관식의 정답 쌍 선택에 적용한다. 주관식에서 올바른 한 쌍만 답해도 정답인 규칙이나, 뜻·음 → 한자 문제에서 모든 쌍을 제시하는 규칙은 바꾸지 않는다.

- 출제 횟수는 개인별 누적 기록을 기준으로 한다. 가족 구성원별로 해당 한자의 뜻·음 쌍 출제 횟수를 따로 관리하며, 다른 사람의 기록을 합산하지 않는다.
- 이전 학습의 출제 횟수도 포함하여 덜 출제한 쌍을 선택한다. 새 학습 회차를 시작해도 누적 출제 횟수를 초기화하지 않는다.

- 한자 → 뜻·음 객관식 문제가 실제로 학습 화면에 표시될 때, 그 문항의 정답으로 선택된 뜻·음 쌍의 개인 누적 출제 횟수를 1회 올린다.
- 답을 제출하지 않고 학습을 나가더라도 이미 표시한 문항은 출제 횟수에 포함한다. 미리 생성하거나 불러오기만 하고 화면에 표시하지 않은 문항은 포함하지 않는다.
- 동일한 문항의 화면 재렌더링이나 새로고침·이어하기로 횟수가 중복 증가하지 않도록 문항별 최초 표시를 기준으로 한 번만 기록한다. 같은 쌍이 새 문항으로 출제되어 표시되면 새 출제로 센다.
- 출제 횟수는 답안 제출·정오 판정·점수 기록과 구분한다. 문제 표시만으로 정답이나 오답을 기록하지 않으며, ‘중도 이탈’과 미표시 문항은 정답률 분모에서 제외한다.

- 출제 가능한 쌍 중 개인 누적 출제 횟수가 가장 적은 쌍을 우선하고, 횟수가 같으면 마지막 출제 시각이 더 오래된 쌍을 우선한다. 최근 출제 시각보다 출제 횟수 비교를 먼저 적용한다.
- 마지막 출제 시각은 해당 쌍의 새 문항이 실제 학습 화면에 처음 표시된 시각으로 기록한다. 동일 문항의 새로고침·이어하기는 출제 횟수뿐 아니라 마지막 출제 시각도 갱신하지 않는다.
- 예를 들어 두 쌍이 각각 3회 출제되었다면 더 오래전에 표시된 쌍을 선택한다. 한 쌍이 2회이고 다른 쌍이 3회라면 마지막 출제 시각과 관계없이 2회인 쌍을 우선한다.
- 한 한자에 복수 뜻·음 쌍이 있는 경우, 단원 내 표기뿐 아니라 **교과서 전체에 수록된 해당 한자의 모든 유효 뜻·음 쌍**을 출제 및 정답 인정 대상으로 사용한다.
- 출제 횟수와 마지막 출제 시각이 모두 같거나 비교 대상이 모두 미출제 상태이면, 그중에서 무작위로 하나를 선택한다.

출제 이력이 없는 쌍은 0회로 취급하고 마지막 출제 시각은 비워 둔다. 이 결정만으로 모든 쌍을 답해야 학습 완료라는 조건을 추가하지 않는다.

### 주관식 뜻과 음 입력 및 제출

- 한자를 보고 뜻·음을 맞히는 주관식은 같은 문제 안에 뜻 입력 칸과 음 입력 칸을 따로 둔다.
- 입력한 뜻과 음은 하나의 제출 버튼으로 함께 제출한다.
- 제출 시 뜻과 음의 정답 여부를 각각 기록하고, 올바른 뜻·음 한 쌍인지 확인하여 문항 점수를 계산한다.
- 한쪽을 입력한 것만으로 먼저 채점하거나 정답을 공개하지 않는다.

뜻과 음 입력 칸을 모두 채워야 일반 제출을 허용한다. 한쪽이 비어 있거나 공백만 있으면 제출할 수 없으며, 모르는 경우 문항 전체의 ‘모르겠어요’ 버튼을 사용한다.

### 주관식의 띄어쓰기 처리

- 뜻과 음 모두 앞뒤 공백과 답 안의 띄어쓰기를 무시하고 채점한다.
- 입력 답안과 등록된 허용 답안에 같은 공백 제거 기준을 적용하여 비교한다. 예를 들어 `한나라`, `한 나라`, ` 한나라 `는 같은 답으로 처리한다.
- 교과서 원문과 허용 답안의 표시 문구는 유지하며, 비교할 때만 공백을 제거한다.
- 띄어쓰기를 무시하더라도 뜻과 음이 같은 뜻·음 묶음에 속해야 한다는 규칙은 유지한다.

공백만 입력한 답은 내용이 없는 답으로 보며, 뜻·음 중 어느 한 칸이라도 이 상태이면 일반 제출을 허용하지 않는다. 띄어쓰기 무시 규칙이 오타나 어미 차이를 자동 허용하는 것은 아니다.

### 주관식의 오타 처리

- 뜻과 음 모두 오타는 오답으로 처리한다.
- 띄어쓰기를 제거한 뒤 등록된 정답 및 허용 답안과 글자가 일치해야 한다. 뜻은 교과서 원문 뜻만 인정하며, 음은 교과서 원문 음과 검수하여 등록한 두음법칙 발음을 인정한다.
- 글자가 비슷하거나 한 글자만 다르다는 이유로 자동 보정하거나 정답으로 인정하지 않는다.

예를 들어 교과서 원문 뜻이 `한나라`일 때 `한 나라`는 일치하지만, `한나리`는 오답이다. 뜻 주관식은 교과서 원문 표기만 허용하며, 음 주관식은 아래의 두음법칙 검수·등록 기준을 적용한다.

### 뜻 주관식의 어미 처리

- 뜻 주관식에서 어미 변형 표현은 허용하지 않는다. 교과서에 수록된 원문 형태 그대로 입력해야 한다.
- 예를 들어 교과서 원문 뜻이 `즐겁다`인 경우 `즐겁다`만 정답이며, 관형사형 어미 변형인 `즐거울` 등은 오답으로 처리한다.
- 어미를 자동으로 정규화하거나 변형된 형태를 정답으로 인정하지 않는다. 앞뒤 공백과 띄어쓰기를 제외하고 원문 표기와 글자가 정확히 일치해야 한다.

### 뜻 주관식의 허용 답안

- 뜻 주관식은 교과서에 정의된 원문 뜻 그대로만 정답으로 인정한다.
- 같은 뜻(동의어)이나 유의어, 구어 표현 등의 추가 허용 답안은 일체 두지 않는다. 교과서 학습 목적상 원문 표기 암기를 원칙으로 한다.
- 채점은 교과서 원문 뜻 목록만을 기준으로 한다. AI가 임의로 의미 유사성을 추정하여 정답으로 인정하지 않는다.
- 한 뜻·음 묶음에 교과서 원문 뜻이 여러 개 수록된 경우(예: `遇`의 `만나다`, `대접하다`), 그중 어느 하나를 정확히 입력하면 정답으로 인정한다.

뜻 주관식은 교과서 원문 뜻만 허용(어미 변형·동의어 불허, 띄어쓰기 무시·오타 불허)하는 것으로 확정했다. 추가 뜻 목록의 작성·검수는 진행하지 않는다.

### 음 주관식의 허용 답안

- 교과서에 수록된 음과 함께, 두음법칙에 따른 발음 중 사전에 검수하여 등록한 답도 정답으로 인정한다.
- 화면에 보여주는 기본 음은 교과서 표기를 유지한다. 추가 허용 발음은 교과서 원문 음과 구분하여 관리한다.
- 허용 발음은 해당 한자의 뜻·음 묶음에 연결한다. 뜻이 달라지는 별도의 독음을 두음법칙에 따른 발음으로 취급하지 않는다.
- 채점은 등록된 허용 발음 목록을 기준으로 한다. 등록하지 않은 발음을 두음법칙으로 자동 변환하거나 AI 판단으로 정답에 추가하지 않는다.

두음법칙에 따른 추가 허용 발음 목록은 [추가 허용 음 검수 자료](참고-추가-허용-음-검수.md)를 바탕으로 29자(`allowedSounds`) 검수 및 데이터 반영을 완료했다(2026-11-21).

### 복수 독음 한자의 주관식

- 교과서 학습 범위 안에서 뜻과 음이 맞는 한 쌍을 답하면 문항 정답으로 인정하고 2점을 준다.
- 교과서에 수록된 모든 뜻·음 쌍을 한꺼번에 답할 필요는 없다.
- 교과서 원문 뜻과 검수하여 등록한 두음법칙 발음도 원래 연결된 뜻·음 묶음 안에서 인정한다.
- 서로 다른 쌍의 뜻과 음을 섞은 답은 문항 오답으로 처리하고 0점을 준다. 뜻과 음을 각각 전체 허용 목록에서 찾는 것만으로 문항을 정답 처리하지 않는다.

| 출제 한자 | 입력한 뜻 | 입력한 음 | 문항 판정 | 점수 |
|---|---|---|---|---:|
| 樂 | 즐겁다 | 락 | 올바른 한 쌍 | 2점 |
| 樂 | 노래 | 악 | 올바른 한 쌍 | 2점 |
| 樂 | 즐겁다 | 악 | 뜻·음 쌍 불일치 | 0점 |
| 樂 | 노래 | 락 | 뜻·음 쌍 불일치 | 0점 |

쌍 불일치는 별도 오류로 표시하고 오답 복습에 포함한다. 결과 화면에서는 뜻·음 각 입력 칸(객관식의 경우 각 선택 영역) 모두에 **‘개별 존재하나 쌍 불일치’** 경고 배지(주황)를 표시하고, 해당 한자의 올바른 뜻·음 쌍 조합 목록을 함께 안내한다. 복습은 원래 문제 형식을 유지하며, 복수 독음의 객관식은 앞서 정한 한 쌍 보기 구성 규칙을 적용한다.

### 뜻과 음을 보고 한자 맞히기: 제시 정보

- 해당 한자의 교과서에 수록된 뜻·음 쌍을 모두 함께 보여준다. 객관식 한자 선택과 주관식 한자 쓰기 모두 이 제시 방식을 적용한다.
- 각 뜻과 음의 연결을 유지하여 쌍별로 구분해 표시한다. 예를 들어 `즐겁다 · 락 / 노래 · 악`을 함께 제시하고 `樂`을 맞히게 한다.
- 교과서 밖의 독음이나 추가 허용 표현을 전부 나열한다는 의미는 아니다. 기본 제시는 교과서 기준을 따른다.

문제에 제시하는 정보와 답으로 요구하는 범위는 구분한다. 뜻·음에서 한자를 맞히는 문제에는 교과서의 뜻·음 쌍을 모두 보여주지만, 반대로 한자를 보고 뜻·음을 입력하는 주관식에서는 올바른 한 쌍만 답해도 정답이다. 모든 쌍을 입력하거나 나머지 쌍의 추가 문제를 통과해야 한다는 조건은 두지 않는다. 한자에서 뜻·음을 고르는 객관식도 기존의 한 쌍 보기 구성 규칙을 유지한다.

### 뜻과 음을 보고 한자 고르기: 객관식 점수

- 뜻·음을 보고 한자를 고르는 객관식은 정답 2점, 오답 0점으로 채점한다.
- 한자에서 뜻·음을 맞히는 문제와 한자 쓰기 문제를 포함해 전 유형의 문항당 만점을 2점으로 통일한다.

‘모르겠어요’를 선택하면 0점 처리·즉시 정답 공개·오답 복습 등록을 적용한다. 보기를 선택하지 않은 상태에서는 제출 버튼을 비활성화한다. 같은 뜻·음에 해당하는 한자가 여러 개인 경우에는 아래 객관식 보기 구성 규칙을 적용한다.

### 뜻과 음을 보고 한자 고르기: 선택 및 제출

- 한자 보기 4개 중 하나를 선택한 뒤 제출 버튼을 눌러 답을 확정한다. 보기를 선택하기 전까지는 제출 버튼을 비활성화한다.
- 제출 전에는 선택한 한자를 바꿀 수 있다.
- 한자를 선택한 것만으로 즉시 채점하거나 정답을 공개하지 않는다. 제출 버튼을 누를 때 선택된 답을 채점하고 결과를 기록한다.
- 정답 2점, 오답 0점의 배점 규칙을 적용하며, 제출 직후 정오 여부와 점수를 즉시 표시하고 틀렸을 때의 정답 내용은 결과 화면에서 공개한다.
- 제출 후 같은 자리에서의 즉시 재시도는 허용하지 않으며, 일반 오답과 ‘모르겠어요’ 모두 원래 형식 그대로 오답 복습에 포함한다.

### 뜻과 음을 보고 한자 고르기: 중복 정답 방지

- 제시한 뜻·음에 맞는 한자가 여러 개여도 객관식 보기는 정답 한자 1개와 오답 한자 3개로 구성한다.
- 정답에 해당하는 한자는 보기 안에 하나만 넣는다. 다른 정답 한자는 오답 후보에서 제외한다.
- 출제 대상 한자가 아니라는 이유만으로, 제시한 뜻·음에 맞는 다른 한자를 오답으로 취급하지 않는다.
- 최종 보기 4개는 서로 다른 한자여야 하며, 정답에 해당하는 보기가 정확히 하나인지 검증한다.

이 규칙은 객관식 보기 구성에 적용한다. 유효한 오답 후보가 3개보다 적으면 아래의 같은 교과서 보충 규칙을 적용한다. 한자 쓰기에서 동음·동의 복수 정답 한자가 있는 경우에는 아래의 쓰기 규칙(부수·총획 힌트로 1자 특정)을 적용한다.

### 객관식 오답 후보의 범위와 보충

- 객관식 오답 보기는 사용자가 선택한 단원의 검수된 데이터에서 우선 고른다. 여러 단원을 선택했다면 선택한 단원 전체를 우선 후보 범위로 삼는다.
- 정답에 해당하는 후보와 중복 보기를 제외한 뒤 유효한 오답이 3개보다 적으면, 부족한 개수만 같은 교과서의 다른 단원에서 보충한다.
