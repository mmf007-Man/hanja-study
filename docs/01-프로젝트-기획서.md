# 프로젝트 기획서

작성일: 2026-11-21 | 상태: 1차 MVP 기획 확정

---

## 1. 프로젝트 비전 및 목적

어린이와 가족이 함께 중학교 한문 교과서 단원 한자의 **뜻·음·자형·필순**을 정확하게 익히고, 오답 복습과 일일 도전을 통해 꾸준히 학습할 수 있는 **모바일·PC 공용 한자 공부 웹앱**을 구축한다.

- **교과서 원문 기준의 정확한 암기**: 천재교과서 2022 개정 중학교 『한문』(안대회 외) 20개 단원 637자를 원문 뜻·음과 한국 정자·필순 기준으로 학습한다.
- **실시간 획 보정 쓰기 학습**: 한 획을 쓰고 손을 떼는 순간(`pointerup`) 입력을 판정해, 통과한 획만 정자 벡터 획으로 즉시 교체하고 잘못된 획은 보존·자동 보정하지 않는다.
- **가족이 한 공간에서 이어가는 학습**: 1차 버전에서는 별도 서버·로그인 없이 기기 내 브라우저에서 가족 구성원별 프로필을 전환하며 학습하고, 향후 서버 기반 클라우드 동기화와 가족 주간 순위 경쟁으로 확장한다.

## 4. 핵심 기능 및 정책 요약

상세 출제·채점·복습·획 보정 규칙은 [학습과 채점 및 획 보정 명세서](02-학습-채점-획보정-명세서.md)를 기준으로 하며, 2026-11-21 확정된 핵심 정책은 다음과 같다.

### 4.1 일반 학습 (회차 · 출제 · 채점)

- **회차 생명주기**: `'시작'` 버튼 클릭 시 회차가 생성되며, 20문제를 모두 완료하거나 사용자가 `'학습 끝내기'`로 중도 종료할 때 종료된다. 브라우저 새로고침 또는 재접속 시 진행 중 회차를 이어한다.
- **중도 종료 처리**: 중도 종료 시 그때까지 완료한 문항만 결과 화면에 공개한다. 화면에 표시되었으나 미제출 상태로 남은 문항은 `'중도 이탈'`(0점 처리, 오답 복습 미등록)로 기록하고, 아직 표시되지 않은 문항은 기록에서 제외한다.
- **유형 선택과 배분**: 4개 유형(① 한자 → 뜻·음 객관식, ② 한자 → 뜻·음 주관식, ③ 뜻·음 → 한자 객관식, ④ 한자 쓰기) 중 원하는 유형을 복수 선택한다. 20문제를 균등 배분(1개: 20, 2개: 10·10, 3개: 7·7·6, 4개: 5·5·5·5)한 뒤 출제 순서를 무작위로 섞는다.
- **중복·반복·불가 처리**:
  - 선택한 단원의 출제 가능 한자가 **20자 이상**이면 같은 회차 내 한자 중복을 허용하지 않는다.
  - **20자 미만**이면 1라운드(전수 출제) 이후 누적 출제 횟수가 적은 한자 순(직전 연속 중복 금지)으로 반복해 20문제를 채운다.
  - 복수 독음 쌍(642쌍)은 교과서 전체 단원 기준으로 누적 출제가 적은 쌍(동률 시 마지막 출제가 오래된 쌍, 최종 동률 시 무작위)을 우선 선택한다.
  - 4지선다 보기 구성이 불가능하거나 쓰기 가능(`strokeStatus == "verified"`) 한자가 없는 경우, 불가 유형/단원을 제외·대체하며 시작 화면에서 사유를 안내하고 시작 버튼을 비활성화한다.
- **제출 및 즉시 피드백**:
  - 모든 문항은 2점(정답) / 0점(오답)으로 채점한다.
  - 한자 → 뜻·음 문제는 뜻과 음을 모두 채워야 제출이 활성화되며, 뜻·음 → 한자 객관식도 한자를 선택해야 제출 버튼이 활성화된다.
  - 힌트 미제공(쓰기 3회 연속 실패 시 점선 가이드만 예외), 제출 직후 즉시 재시도는 허용하지 않는다.
  - **진행 중 정오 여부와 누적 점수는 즉시 표시**하되, 틀렸을 때의 **정답 내용은 회차 종료 후 결과 화면에서 일괄 공개**한다. 단, `'모르겠어요'`를 누른 문항만 예외로 0점 확정과 동시에 정답을 즉시 공개한다.
- **쌍 불일치 피드백**: 복수 독음 한자에서 뜻과 음이 각각 존재하나 서로 다른 쌍을 섞은 답(예: `樂`에 `즐겁다·악`)은 0점·오답 복습 등록과 함께 뜻·음 입력 칸에 **주황 경고(`개별 존재하나 쌍 불일치`)**를 표시하고 결과 화면에서 올바른 쌍 조합 전체를 안내한다.
- **두 가지 정답률 산출**:
  - **문항 정답률**: `정답 문항 수 ÷ 확정 응답 문항 수(일반 제출 + '모르겠어요')` (`'중도 이탈'` 제외)
  - **뜻·음 개별 정답률**: `개별 항목 정답 수 ÷ 일반 제출 문항 수` (`'모르겠어요'`와 `'중도 이탈'` 제외, `'모르겠어요'`는 별도 건수로 표기)

### 4.2 오답 복습 정책

- **대상**: 한자 → 뜻·음 객관식/주관식 오답뿐 아니라 **뜻·음 → 한자 객관식 오답** 및 쓰기 오답, `'모르겠어요'` 문항까지 모두 복습 대기열에 포함한다.
- **출제 순서**: 대기열은 선입선출(FIFO)과 연속 정답 횟수가 적은 순을 조합해 출제하며, 직전 문항과 같은 항목을 연속 출제하지 않는다.
- **1개 잔여 시 삽입**: 대기 항목이 1개만 남으면 같은 단원(없으면 다른 단원)의 다른 한자 일반 문제 1개를 사이에 넣어 출제한 뒤 남은 항목을 재출제한다. 이때 **일반 학습/삽입 문제 정답은 복습 연속 정답 횟수에 합산하지 않는다.**
- **완료·편입·종료**: 대기 중인 모든 항목이 한 회차 내에서 **연속 2회 정답**을 달성하면 복습 회차를 종료한다(중간에 일반 문제 오답이 발생하면 복습 대기열에 새로 편입). 언제든 중도 종료할 수 있으며, 미완료 상태에서 새 복습 회차를 시작하면 연속 횟수는 0으로 초기화된다.

### 4.3 쓰기 문제 정책

- **목표 한자 특정**: 동음·동의 한자 혼동을 막기 위해 교과서 모든 뜻·음 쌍과 함께 **부수 및 총획 힌트**를 제시해 목표 한자 1자를 명확히 특정한다.
- **배점**: 다른 유형과 동일하게 문항 완료 시 **2점**으로 통일한다(`'모르겠어요'` 또는 중도 이탈 시 0점).
- **보정 및 실패 처리**: 매 획 입력 종료 시 판정해 통과하면 정자 획으로 즉시 교체한다. 획 실패 시 직전에 통과한 성공 획은 유지한 채 해당 획을 다시 입력하게 하며, **한 획에서 3회 연속 실패하면 해당 획의 점선 가이드를 표시**하고 가이드 사용 여부를 기록에 남긴다.

## 5. 가족 프로필 및 하루 도전 정책

- **가족 프로필 (1차 로컬 구현)**:
  - 프로필 속성: `profileId`, `name`(닉네임), `avatar`(선택 아이콘/색상), `createdAt`.
  - 개인별 분리 데이터: 학습 회차 이력, 복습 대기열 및 완료 이력, 뜻·음 쌍 개인 누적 출제 횟수/마지막 출제 시각, 하루 도전 결과.
  - 백업/복원: 전체 프로필 또는 개별 프로필 데이터를 JSON 파일로 내보내고, 다른 브라우저나 기기에서 불러와 복원할 수 있다.
- **하루 도전 (Daily Challenge)**:
  - **동일 조건 보장**: `YYYY-MM-DD` 날짜 문자열을 시드(PRNG)로 사용해, 같은 날 도전하는 모든 가족 프로필에 동일한 20문제 세트(유형·한자·보기 순서)를 생성한다.
  - **참여 규칙**: 프로필당 하루 1회 공식 기록을 인정하며(재도전 시 연습 기록으로 분리하거나 최초 기록 유지), 1차 버전에서는 기기 내 프로필 간 일일 점수·정답률·소요 시간을 결과 화면에서 비교한다.
  - **2차 확장**: 서버 도입 시 주간 누적 순위표와 서버 측 정답 검증으로 확장한다.
